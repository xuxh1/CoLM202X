## 4. 目录

- `v2/目标与判据.md`：全球与站点的判据、接受一项改动的条件、参数原则。

## 5. 怎么退回

- 代码：每项改动单独一个 commit，`git revert <sha>` 即退回；能加 namelist 开关的改动都带开关，关掉即回到上一版行为。
- 配置：每个 tag 的 `_conf/` 保存完整配置，`_conf/logs/conf_diff_vs_<父 tag>.txt` 记录与父 tag 的差异。
