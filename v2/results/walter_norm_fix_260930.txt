## 1. 结论

1. 错在哪：`methane_prod` 先只在水位以下层（j > jwt）上算归一化因子 walter_renorm = Σ hr_vr·dz ÷ Σ hr_vr·dz·exp(−z/z0)（基线 Physics.F90:2335-2347），再在层循环里对每一层都做 partition_z ← partition_z·exp(−z/z0)·walter_renorm（基线 2543-2545，无 j > jwt 条件）。partition_z 同时决定该层分解碳 `carbon_decomp_depth`（基线 2649），进而决定产量上限、O2 需求（2716-2717）与 CO2 诊断（2739-2741）。水位以下只有第 10 层（节点 2.865 m）时因子为 exp(2.865/0.3) ≈ 1.4 万，水位以上各层的 O2 需求与 CO2 被放大约同倍数——已验证（读码基线 Physics.F90:2335-2347、2539-2545、2649-2741）。
2. 受影响的路径：只有 1 ≤ jwt ≤ 9 的子柱被放大，即土壤斑块（旱地、洪泛格、稻田）与湿地斑块的非饱和子柱在水位深于第 1 层时；jwt = 10（水位在柱底以下，或湿地 dry-unsat 分支）时因子为 1，各层只乘 exp(−z/z0)，O2 需求与 CO2 反被压低；所有斑块的饱和子柱（jwt_sat = 0）与水位在第 1 层内的非饱和子柱，归一化范围与作用范围一致，不受影响；湖泊不经 partition_z——已验证（读码 Physics.F90:1409-1424、1601、2336、2432-2479、2543）。
3. CTSM 对照：`ch4_prod` 没有深度衰减，产量与 O2 需求共用同一个 partition_z = hr_vr·dz/(somhr+lithr)（ch4Mod.F90:2559-2563、2630、2658-2667）；CTSM 的 O2 需求取该层全部分解碳（不减 2 倍产量），`co2_decomp_depth` 在 `ch4_prod` 里只关联不赋值（2395、2440、2445）——已验证（读码 CTSM ch4Mod.F90）。

## 2. 读码

### 2.1 partition_z 的构造

1. 初值 partition_z = 1（2324）；每层先取宿主 HR 分层 hr_vr(j)·dz(j)/(somhr+lithr)，somhr+lithr ≤ 0 时取 1（2532-2537）——已验证（读码）。
2. 预处理：z0_methane_prod > 0 且非湖泊时，只在 j > jwt 的层上累加 walter_w_raw = Σ hr_vr·dz 与 walter_w_atten = Σ hr_vr·dz·exp(−z/z0)，walter_renorm = raw/atten，atten = 0（无水位以下层）时保持 1（2335-2347）。注释的意图是"只纳入本分支能产甲烷的层"（2330-2334）——已验证（读码）。
3. Const.F90:199-217 把它定义为"甲烷生成的深度衰减"（Walter & Heimann 2001，z0 取 0.30 m），ch4_parameter.nml:119 设 0.30——已验证（读码与配置）。所以衰减的对象是产甲烷的分层分配；归一化保证水位以下层的权重和不变。
4. 基线层循环对每一层都乘 exp(−z/z0)·walter_renorm（基线 2543-2545）。于是 Σ_{j>jwt} partition_z 守恒，但 j ≤ jwt 的层被乘上一个只按水位以下层算出的因子——已验证（读码）。

### 2.3 各路径

1. 饱和子柱：所有斑块 jwt_sat = 0（1601），预处理对全柱归一化，作用范围与归一化范围一致，只把分解与产量往表层挪、不改总量——已验证（读码）。
2. 非饱和子柱：jwt_unsat 取水位所在层之上一层（1415-1424），全深 10 层；湿地斑块开 `wetland_dry_unsat_branch` 时 jwt_unsat = nl_soil（1409-1413）。`inundation_mode = 'colm'`（ch4_parameter.nml:71）把该分支关掉（Const.F90:1475-1488），湿地非饱和子柱同样按水位算——已验证（读码与配置）。
3. 土壤斑块（旱地、洪泛格的两个子柱、稻田）都走同一个 `methane_prod`，稻田只在淹水份额与 C-14 豁免上不同（1066-1125、1073-1074）——已验证（读码）。
4. 湖泊：预处理与层循环的衰减都排除 patchtype 4（2336、2543），湖泊分支在 2478 `cycle` 前算完，不用 partition_z——已验证（读码）。
5. 因此放大只发生在 1 ≤ jwt ≤ 9 的非饱和子柱，倍数约 exp(z_{jwt+1}/z0) 量级：jwt = 9 时约 1.4 万，jwt = 8 时约 620（lit_upland 结论 7 的两档）；jwt = 10 时因子为 1，各层只剩 exp(−z/z0)，O2 需求与 CO2 被压低——已验证（读码；US-Myb 键开逐位不变印证 jwt = 0 路径不受影响）。

1. partition_z：VERTSOILC 时取 hr_vr·dz/(somhr+lithr)，否则按根分布（ch4Mod.F90:2552-2563）；没有深度衰减——已验证（读码；`exp(-z(c,j)`、`z0` 0 处命中）。

3. 产量：j > jwt 时 f_ch4_adj·base_decomp·partition_z/dz，水位以上只有 anoxicmicrosites（2658-2667）——已验证（读码）。

## 3. 实现

### 3.1 改法与键

1. 键：`DEF_METHANE%walter_norm_fix`，logical，缺省 .false.，随 DEF_METHANE 整体经 namelist `nl_colm_methane_parameter` 读入（各进程各自读，Const.F90 `read_methane_namelist`），无需另加广播——已验证（读码 Const.F90 read_methane_namelist）。
2. 代码（Physics.F90:2543-2549）：`if (.not. DEF_METHANE%walter_norm_fix .or. j > jwt)` 时才乘 exp(−z/z0)·walter_renorm。关时与基线同一表达式、同一运算顺序，所以逐位不变——已验证（第 4.2 节）。
3. 开时的性质：水位以下层的 partition_z 之和等于这些层的宿主 HR 份额之和（由归一化保证），水位以上层就是宿主 HR 份额，所以子柱分解碳之和等于 base_decomp，即宿主 HR（乘上 C-14、SIF 等已有因子）；每层产量 = f_adj·分解碳，f_adj ≤ 0.5（2646），所以 O2 需求 = 分解碳·(1 − 2 f_adj) ≥ 0、不会被截断——已验证（读码推导）。
4. commit：92ba35ae `fix(methane): Walter depth attenuation only below the water table (I-37)`，改 Const.F90 +15 行、Physics.F90 +5/−1 行——已验证（`git show --stat 92ba35ae`）。

### 3.2 为什么不照任务书的写法

1. 任务书写法（记作写法 A）：所有层的分解碳、O2 需求、CO2 都用未衰减的 HR 分层，只让产量用衰减分层。本实现（写法 B）：衰减只在水位以下层，且该层分解碳与产量同用衰减分层。
2. 在 jwt ≥ 1 的非饱和子柱，A 与 B 只在水位以下层内部不同；只有第 10 层在水位以下时两者完全相同（w_10 = raw_10）——已验证（读码推导）。
3. 在 jwt = 0 的子柱（所有饱和子柱，即湿地与淹水部分的主体），A 会改变现状，B 不改。A 下表层某层产量 = f_adj·exp(−z/z0)·renorm·raw，可超过该层未衰减分解碳的一半：renorm 在全柱归一化时大于 1，表层 exp(−z/z0) 近 1，f_adj 最大 0.5，于是 O2 需求 max(0, raw − 2P) 被截到 0，CO2 max(0, raw − P + rr) 也可能被截，截断处子柱碳不再闭合——已验证（读码 2663、2720、2743 的 max 截断与 2646 的上限）。
4. B 的依据：CTSM 每层一个 partition_z 同时给产量与 O2 需求（第 2.4 节）；Walter 衰减的物理含义是新鲜底物集中在上部，底物集中处分解也集中，CH4 与 CO2 应出自同一份分解碳（2CH2O → CH4 + CO2，2647-2651 注释）。A 在饱和子柱表层把深层碳"搬上来"产甲烷却不计它的分解，属于新的建模选择，不是修错——推测。理由是任务书与 lit_upland 第 3.3 节第 6 条都把 jwt = 0 的表层需求上移列为"量级未算"的另一问题。
5. 若中控要 A，可在 B 之上再加一个只作用于 jwt = 0 子柱的键，另跑湿地组——存疑（量级未知，要跑湿地塔才能定）。
